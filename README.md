## About

This is a personal lab. Some folders hold tools I actually use, some hold experiments I built to learn something, and some hold code that exists just because it was fun to write. Each language has its own space, so it's easy to find what you're looking for.

## Spaces

| Space | Language | What's inside |
| --- | --- | --- |
| [Python Workshop](Python%20Workshop) | Python | Exercise collection (primes, Collatz, GCD/LCM, invoices, progressive taxes) and two versions of a Snake game with a GUI. |
| [Lua Sandbox](Lua%20Sandbox) | Lua | Small scripts and experiments, including Byte Cat, a terminal virtual pet. |
| [C++ Forge](C%2B%2B%20Forge) | C++20 | Projects and utilities in C++. Starts with Hello World. |
| [Java Playground](Java%20Playground) | Java | Programs, tools and experiments in Java. Starts with Hello World. |
| [Assembly Vault](Assembly%20Vault) | x86-64 NASM | Low-level experiments that talk directly to the Linux kernel. Starts with Hello World. |
| [Axioma](Axioma) | Python, C++ | A programming language built from scratch, with its own interpreter, an IDE, and a calculator app that uses a C++ evaluator through pybind11. |

## Highlights

- **Axioma:** a custom language with a lexer, parser, interpreter and support for structures (linked lists, trees and graphs). Source files use the `.axm` extension.
- **My First Calculator:** a desktop calculator with a GUI, scientific functions, persistent history, a base converter and an ASCII table, plus unit tests.
- **Snake:** two independent versions of the same game, each with its own matrix logic and GUI.
